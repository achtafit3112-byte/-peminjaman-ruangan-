# SIPERU - Sistem Informasi Peminjaman Ruangan

Project remedial Praktikum Pemrograman Berbasis Web.

## Tujuan
Membantu pengelolaan data ruangan dan proses peminjaman ruangan secara terkomputerisasi.

## Fitur
- Login admin
- Dashboard
- CRUD data ruangan
- Pengajuan peminjaman
- Pemeriksaan jadwal bentrok
- Persetujuan/penolakan peminjaman
- Laporan peminjaman
- Cetak laporan

## Teknologi
PHP Native, MySQL, HTML, CSS, JavaScript, Bootstrap 5, XAMPP, VS Code.

## Menjalankan
Simpan folder di C:/xampp/htdocs/peminjaman-ruangan.
Start Apache dan MySQL pada XAMPP.
Import database.sql melalui phpMyAdmin.
Buka http://localhost/peminjaman-ruangan/
